# Changelog

## 18.0.1.2.0

- Los contactos creados por vendedores restringidos se autoasignan al creador.
- Las órdenes de venta asignan al vendedor como responsable y usuario autorizado.
- Las autorizaciones históricas se conservan al cambiar de vendedor.

## 18.0.1.1.0

- La restricción ahora parte de cero contactos visibles.
- Se eliminó la dependencia funcional del check de contacto restringido.
- Nuevo menú visible sin modo desarrollador para asignar contactos.

## 18.0.1.0.0

- Perfil restringido y perfil Alfa para contactos.
- Marca de contacto restringido y usuarios autorizados.
- Asignación automática desde órdenes de venta.
- Sincronización inicial de órdenes existentes.
- Protección mediante regla de registro.
